Week 1 – News Sentiment Stock Analysis

This project analyzes the relationship between news sentiment and stock price movements.
It pulls financial or company-related news, processes text data, performs sentiment analysis, and compares sentiment scores with stock trends to observe patterns and correlations.

This repository is part of a multi-week learning challenge focusing on data analysis, machine learning, and real-world financial insights.

Project Objectives

Collect news headlines or articles related to selected companies or indices

Preprocess and clean text data

Apply sentiment analysis (using TextBlob/VADER/transformers)

Visualize sentiment trends over time

Compare sentiment results with stock price movements

Generate insights about how news affects market performance
